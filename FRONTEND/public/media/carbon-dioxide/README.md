Browser-verified video dimensions: 4096 × 2048; duration: 39.2 seconds. The file
was downloaded directly; no media conversion tools or packages were installed.
The native 2:1 combined surface/CO₂ frames map onto the globe's existing sphere
UVs. Background imagery is NASA's original composite, not our January 2004
reference texture. Geographic orientation, coastlines, pause and zoom were
visually checked. The original sequence restarts without a seam correction.

The original colorbar is retained intact. The always-visible strip uses an SVG
viewBox (x=238, y=323, width=1444, height=216) for the color/opacity band, with
readable DOM ticks matching the source's 380, 400, 420, 440 and 460 ppm labels.
No color gradient is reconstructed. Checkerboard areas illustrate transparency,
not CO₂ absence.

This is historical rendered model imagery. The spherical image has no independent
altitude/volume exploration. Selected coordinates remain pins, not ppm samples;
no per-location measurements or data-derived audio are claimed. The source's
timestamp list is not used; no unverified per-frame dates are displayed.

The local assets are served through BASE_URL and copied unchanged by Vite into
the production output, independently of the JavaScript bundle. The video is
approximately 84.6 MiB. Keep the exact source file/checksum when sharing it.
