# Earth Jukebox — Agent Instructions

Before implementing or modifying any code,
read and follow `guideline/README.md`.

## Mandatory Rules

- Preserve the agreed science-book design.
- Follow the project architecture and folder structure.
- Respect feature ownership between frontend developers.
- Reuse existing components, types and utilities.
- Do not add dependencies without justification.
- Do not modify unrelated files.
- Do not invent NASA data or scientific values.
- Coordinate changes to shared types and state.

## Validation

After implementation:

1. Run `npm run lint`.
2. Run `npm run build`.
3. Report modified files and actual test results.
4. Report assumptions, unresolved issues and blockers.
